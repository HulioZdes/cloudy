# Weather Journal

A lightweight Ruby application for keeping a personal weather journal.

## Overview

Weather Journal is a simple console application that stores daily weather observations, displays entries, and calculates basic statistics.

The project demonstrates Ruby classes, modules, arrays, and object-oriented programming.

## Features

- Add weather entries
- Display all records
- Average temperature
- Rainy day counter
- Warmest day
- Clean console formatting
